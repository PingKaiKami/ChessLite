# ChessLite

ChessLite 是一款可直接在瀏覽器離線遊玩的單機西洋棋。玩家執白棋，與內建的純 JavaScript AI 對戰，不需要安裝套件、啟動伺服器或連接網路。

線上遊玩：<https://pingkaikami.github.io/ChessLite/>

## 開始遊玩

1. 下載專案中的 `index.html`。
2. 使用 Chrome、Edge 或 Firefox 直接開啟檔案。
3. 選擇棋子後點擊合法落點，或將棋子拖曳到目標格。

## 主要功能

- 完整西洋棋規則，包括將軍、將死、王車易位、吃過路兵及四種兵升變。
- 支援逼和、棋力不足、三次重複局面及 50 回合規則。
- 簡單、中等、困難三種 AI 難度。
- 玩家與 AI 各有 10 分鐘棋鐘；玩家完成第一步後開始計時。
- 點擊與滑鼠／觸控拖曳操作。
- 走棋紀錄、悔棋、重新開始及投降功能。
- 內建離線落子、吃子、易位、將軍與終局音效。
- 支援桌面與手機響應式版面。

## AI 難度

- **簡單**：快速搜尋，偶爾選擇較弱走法。
- **中等**：使用迭代加深與戰術搜尋。
- **困難**：使用較深搜尋、置換表、走法排序及將軍延伸。

AI 完全在瀏覽器本機執行，不使用 Stockfish、雲端服務或外部 API。

## 技術

HTML5、CSS3 與原生 JavaScript。所有介面、棋子 SVG、規則引擎、AI 與音效皆包含在單一 `index.html` 中。
